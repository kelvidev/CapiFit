Deslizar entre telas:
- Tela de Login leva para a Tela Inicial.
- Tela Inicial ao deslizar para esquerda, mostra a Tela de Histórico.
- Tela Inicial ao deslizar para direita, mostra a Tela de Perfil.
- Tela de Histórico ao arrastar para a direita, mostra a Tela Inicial.
- Tela de Perfil ao deslizar para a esquerda mostra a Tela Inicial.
- Botão "Home" no menu superior direito leva para a Tela Inicial (de qualquer lugar, menos a própria tela inicial).
- Botão da Foto do Atleta leva para a Tela de Configurações.
